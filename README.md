<h1>
  🚀 CrumbSpace
</h1>

**Crumbspace** is a 2D arcade game developed in **Unity**, designed around simple one-button controls and progressively harder gameplay.

Each level introduces different combinations of asteroid patterns, collectibles and power-ups. The final bonus stage removes the normal time limit and continuously increases the difficulty until the player is defeated.

✨ **Crumbspace** is a personal project created to practice and improve my skills in Unity, C#, mobile development, gameplay systems, object pooling, UI, save systems and performance optimization.

## 🕹️ How to Play

- **Tap / Click**: Make the ship move upward.
- **Avoid asteroids**: Colliding with an asteroid or falling out of bounds ends the current attempt.
- **Collect stars and croissants**: Increase your score.
- **Use power-ups**: Special items can temporarily change the gameplay or help you survive.
- **Complete each level**: Survive until the timer reaches zero.
- **Final Bonus Level**: Survive as long as possible while the difficulty continuously increases.

---

## ⭐ Collectibles

Different collectibles appear during the game:

- ⭐ **Stars**: Add points to your score.
- 🥐 **Croissants**: Add points to your score.

---

## ⚡ Power-Ups

- 🧲 **Magnet**: Attracts collectibles toward the player for a limited time.
- 🔥 **Missile**: Eliminates the UFO.
- 🧪 **Invisibility**: Temporarily protects the player from asteroid collisions.
- ❄️ **Snow**: Slows down asteroids, collectibles and power-ups.
- 🧨 **Dynamite**: Destroys all active asteroids currently on screen.

The number and type of available power-ups can change depending on the level.

---

## 🛸 UFO

A UFO follows the player's vertical movement during the game.

The UFO can collide with asteroids and can be destroyed for extra points. After a short delay, it returns and continues following the player.

---

## 📈 Level Progression

Each level can define different gameplay parameters, including:

- Asteroid spawn frequency.
- Available asteroid types.
- Collectible spawn rate.
- Power-up availability.
- Level duration.
- Bonus level behaviour.

The final stage is an endless bonus level with no countdown. Instead, the difficulty keeps increasing over time as asteroids move faster and appear more frequently.

---

## 🏆 Score System

- Stars collected: +10
- Croissants collected: +25
- Aliens destroyed: +50
- Final Stage Star: +20
- Final Stage Croissant: +50

After completing the run, the player can save their name and final score to a local high-score ranking.

## 🎮 Features

- 2D arcade gameplay.
- Multiple progressively harder levels.
- Endless final bonus stage.
- Local high-score system.
- Spanish and English language support.
- Music and sound settings.
- Mobile-friendly UI.
- Object pooling for gameplay objects and effects.
- Optimized for mobile devices.
- Performance tested and profiled on a physical Android device using the Unity Profiler.

## 🚀 How to Run

### 📱 Android

1. Download **[Crumbspace for Android](https://github.com/jenhmy/crumbspace/releases/download/v1.0.0/Crumbspace_Android_v1.0.apk)**.
2. Open the APK on your Android device.
3. Allow installation from unknown sources if Android asks for permission.
4. Install and launch **Crumbspace**.

> Android may display a warning because the APK is installed outside the Google Play Store. This is expected for apps distributed directly through GitHub.

### 🖥️ Windows

1. Download **[Crumbspace for Windows](https://github.com/jenhmy/crumbspace/releases/download/v1.0.0/Crumbspace_Windows_v1.0.zip)**.
2. Extract the ZIP file.
3. Open the extracted folder.
4. Run `Crumbspace.exe`.

> Keep all extracted files and folders together.

> Windows Defender SmartScreen may display a warning because the executable is not digitally signed. If that happens, click **More info** → **Run anyway**.
